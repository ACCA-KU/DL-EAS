# DL-EAS
Deep Learning-based  Electronic Absorption Spectrometer (DL-EAS) contribution by kiwoong Lee

This repository contains the code and sample data for running predictions using the DL-EAS model.  
The DL-EAS model is also accessible as a web-based application at [http://deep4chem.korea.ac.kr/ACCA/prediction/DLEAS](http://deep4chem.korea.ac.kr/ACCA/prediction/DLEAS).
